## Project Overview
A full-featured e-commerce backend (FastAPI + PostgreSQL) with a vanilla HTML/CSS/JS SPA frontend served as static files from the backend at root `/`. All API routes are under `/api/`.

## Tech Stack
- **Backend**: Python FastAPI, SQLAlchemy, PostgreSQL
- **Frontend**: Vanilla HTML/CSS/JS (NO frameworks, NO build step, NO Vite, NO npm)
- **Auth**: JWT tokens stored in localStorage
- **DB**: PostgreSQL at `postgresql://postgres:Calculator@localhost:5432/ecommerce_inventory_db`

## API Endpoints
All under `/api` prefix:
- `POST /api/auth/register` / `POST /api/auth/login` / `GET /api/auth/me`
- `GET/POST/PUT/DELETE /api/categories`
- `GET /api/products` + `POST/PUT/DELETE /api/products/{id}` + `POST /api/products/bulk-stock-update`
- `GET /api/orders` + `POST /api/orders` + `PUT /api/orders/{id}/status`
- `GET /api/reviews` + `POST /api/reviews`
- `POST /api/upload/image`
- `GET/POST /api/contact_messages` + `PUT /api/contact_messages/{id}/read`
- `GET /api/admin/stats` + `GET /api/admin/users` + `DELETE /api/admin/users/{id}`

## Key Architectural Decisions
- `NullPool` + `pool_pre_ping=True` in DB config to survive PostgreSQL restarts
- `create_all` runs on app startup — new tables/columns auto-created
- Cart in `localStorage`, validated against server stock on page load
- Pagination: server uses `skip`+`limit`, shop frontend slices client-side (12/page)
- Reviews in separate table with unique constraint per product+user
- Image uploads stored at `uploads/`, served via `StaticFiles` mount
- Unsplash direct URL format: `https://images.unsplash.com/photo-{ID}?w=500&h=500&fit=crop`
- No wrapper object on paginated responses — returns items array directly

## Running the Project
```bash
uvicorn app.main:app --reload --port 8000
```
Opens at `http://localhost:8000/`

## Important Notes
- NEVER add build steps, npm packages, or frameworks to the frontend
- All new frontend code goes in the existing `index.html`, `app.js`, or `styles.css`
- Models are in `app/models.py`, routes in `app/routers/`, schemas in `app/schemas.py`
- Use `seed_full.py` for a complete DB reset with all data
- `fix_images.py` updates product image URLs by product name matches
- Dark mode toggle is in Profile page, persisted in localStorage
